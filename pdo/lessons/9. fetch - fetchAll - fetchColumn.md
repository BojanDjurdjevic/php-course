# 9. fetch - fetchAll - fetchColumn

## Lekcija 9 — `fetch()`, `fetchAll()` i `fetchColumn()`

Sada prelazimo na drugu stranu PDO toka.
Do sada smo radili:

```text
PHP
→ PDO
→ MySQL
```

Sada gledamo povratak:

```text
MySQL rezultat
→ PDOStatement
→ PHP
```

Recimo:

```php
$stmt = $pdo->prepare(
    'SELECT id, name, email
     FROM users
     WHERE id = :id'
);

$stmt->execute([
    'id' => 5,
]);
```

Query je izvršen.
Ali rezultat još nismo izvukli u PHP promenljivu.
Tu dolazi:

```php
$stmt->fetch();

fetch()
```

`fetch()` uzima jedan sledeći red iz result set-a.

```php
$user = $stmt->fetch(PDO::FETCH_ASSOC);
```

može vratiti:

```php
[
    'id' => 5,
    'name' => 'Bojan',
    'email' => 'bojan@example.com',
]
```

Ako nema više redova:

false

Zato često vidiš:

```php
$user = $stmt->fetch(PDO::FETCH_ASSOC);

if (!$user) {
    // user not found
}
```

Mentalno:

```text
fetch()
→ daj mi sledeći red
```

Ako result ima 100 redova:

```php
$row1 = $stmt->fetch();
$row2 = $stmt->fetch();
$row3 = $stmt->fetch();
```

svaki poziv pomera cursor na sledeći red.

```php
fetchAll()
```

Ako želiš sve redove odjednom:

```php
$users = $stmt->fetchAll(PDO::FETCH_ASSOC);
```

dobiješ:

```php
[
    [
        'id' => 1,
        'name' => 'Ana',
    ],
    [
        'id' => 2,
        'name' => 'Marko',
    ],
    [
        'id' => 3,
        'name' => 'Bojan',
    ],
]
```

Mentalno:

```text
fetchAll()
→ učitaj sve preostale redove u PHP
```

To je praktično, ali ima važnu cenu:

```text
veliki result set
→ mnogo PHP memorije
```

Ako query vrati 500.000 redova, `fetchAll()` može biti vrlo loša ideja.
Tada je bolje:

```php
while ($row = $stmt->fetch(PDO::FETCH_ASSOC)) {
    // obrađuj red po red
}
```

To je mnogo štedljivije po memoriji.

```php
fetchColumn()
```

Kad ti treba samo jedna vrednost:

```php
$stmt = $pdo->query(
    'SELECT COUNT(*) FROM users'
);

$count = $stmt->fetchColumn();
```

Ako query vrati:

```php
COUNT(*)
```

---

153

`fetchColumn()` ti direktno daje:

153

bez potrebe za:

```php
$row = $stmt->fetch();
$count = $row['COUNT(*)'];
```

Još lepše uz alias:

```php
$stmt = $pdo->query(
    'SELECT COUNT(*) AS total FROM users'
);

$count = $stmt->fetchColumn();
```

Ali `fetchColumn()` gleda kolonu po poziciji, najčešće prvu.
`PDO::FETCH_ASSOC`
Ako smo konekciju napravili sa:

`PDO::ATTR_DEFAULT_FETCH_MODE` => `PDO::FETCH_ASSOC`

onda možemo jednostavno:

```php
$user = $stmt->fetch();
```

i dobićemo associative array.
Bez tog default-a, PDO može imati drugi fetch mode, pa je dobro da znaš da fetch mode utiče na oblik rezultata.
Najvažnije:

```text
fetch()
→ jedan red
```

```text
fetchAll()
→ svi redovi
```

```text
fetchColumn()
→ jedna vrednost iz jedne kolone
```

I još:

```text
fetchAll()
→ praktično za mali/srednji rezultat
```

```text
fetch() u petlji
→ bolje za veoma veliki result set
```

## Mini interview pitanje 9

Koja je razlika između:

```php
fetch()
fetchAll()
fetchColumn()
```

i zašto `fetchAll()` može biti loš izbor ako query vraća ogroman broj redova?

---

`fetch()` - uzima jedan red
`fetchAll()` - uzima sve redove
`fetchColumn()` - uzima 1 kolonu.

Za veliki br redova, los izbor je fetchAll zbog memorije, bolje je uzimati red po red.

---

Tačno — 9.7/10.
Samo jedna važna nijansa za `fetchColumn()`:

```text
fetchColumn()
→ ne uzima "celu kolonu iz svih redova"
→ uzima vrednost jedne kolone iz sledećeg reda
```

Najčešće ga koristiš za nešto poput:

```php
$stmt = $pdo->query('SELECT COUNT(*) FROM users');

$count = $stmt->fetchColumn();
```

Dakle dobiješ jednu scalar vrednost.
A za veliki rezultat si potpuno tačno rekao:

```text
fetchAll()
→ učita sve u PHP memoriju odjednom
```

```text
fetch() u while petlji
→ obrađuje red po red
→ mnogo pogodnije za ogroman rezultat
```
