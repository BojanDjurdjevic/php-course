# 15. FETCH modes

## Lekcija 15 — fetch mode-ovi: FETCH_ASSOC, FETCH_OBJ, FETCH_CLASS

Do sada smo uglavnom koristili:

```php
$stmt->fetch(PDO::FETCH_ASSOC);
```

što daje:

```php
[
    'id' => 5,
    'name' => 'Bojan',
]
```

Ali PDO može rezultat mapirati i drugačije.
`PDO::FETCH_OBJ`:

```php
$user = $stmt->fetch(PDO::FETCH_OBJ);
```

daje objekat tipa stdClass, pa pristupaš ovako:

```php
echo $user->name;
```

umesto:

```php
echo $user['name'];
```

Još zanimljivije je:

`PDO::FETCH_CLASS`

Recimo:

```php
class User
{
    public int $id;
    public string $name;
}
```

Možeš da kažeš PDO-u da red mapira u objekat te klase:

```php
$stmt->setFetchMode(PDO::FETCH_CLASS, User::class);

$user = $stmt->fetch();
```

i dobiješ objekat:

```php
$user->id;
$user->name;
```

Mentalno:

```text
FETCH_ASSOC
→ associative array
```

```text
FETCH_OBJ
→ stdClass objekat
```

```text
FETCH_CLASS
→ instanca konkretne klase
```

Ali ovo je važno: FETCH_CLASS nije ORM.
PDO samo mapira kolone na properties objekta. Nema automatski:

```text
relations
dirty tracking
save()
delete()
casts
events
```

kao Eloquent.
Dakle:

```text
PDO FETCH_CLASS
→ row mapping
```

```text
Eloquent
→ mnogo bogatiji ORM sloj
```

## `PDO::FETCH_OBJ` - u vidu objekta stdClass

`PDO::FETCH_CLASS` - mapira polja iz baze na properties jedne klase, na primer User

Ipak, ovo poslednje nije ORM, samo mapira polja na properties
