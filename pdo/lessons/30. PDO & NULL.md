# 30. PDO & NULL

## Lekcija 30 — PDO i NULL

Ovo je mala tema, ali vrlo praktična.

Recimo:

```php
$deletedAt = null;
```

i želimo:

```text
UPDATE users
SET deleted_at = :deleted_at
WHERE id = :id
```

Možemo:

```php
$stmt->bindValue(
    ':deleted_at',
    null,
    PDO::PARAM_NULL
);
```

pa baza dobija pravi SQL:

NULL

a ne string:

"NULL"

To je ista razlika koju smo već imali u MySQL modulu:

deleted_at = NULL       -- SQL NULL vrednost

nije isto što i:

deleted_at = 'NULL'     -- običan string

Ali postoji još jedna važnija stvar.
Ako želiš da pronađeš redove gde je deleted_at NULL, ne radiš:

```sql
WHERE deleted_at = :deleted_at
```

pa proslediš:

null

Jer u SQL-u:

column = NULL

nije TRUE.
Za NULL koristimo:

```sql
WHERE deleted_at IS NULL
```

ili:

```sql
WHERE deleted_at IS NOT NULL
```

Dakle placeholder rešava prosleđivanje NULL vrednosti, ali ne menja SQL pravila three-valued logic.
Mentalno:

```text
INSERT / UPDATE vrednost NULL
→ placeholder + PARAM_NULL je okej
```

```text
provera da li kolona jeste NULL
→ IS NULL
```

```text
provera da nije NULL
→ IS NOT NULL
```

## Mini interview pitanje 31

Zašto ovo nije pravi query:

```php
$stmt = $pdo->prepare(
    'SELECT *
     FROM users
     WHERE deleted_at = :deleted_at'
);

$stmt->execute([
    'deleted_at' => null,
]);
```

ako želimo sve user-e gde je deleted_at NULL?

## Šta bi trebalo napisati u SQL-u?

---

## U SQL-u treba napisati

```sql
WHERE IS (ili NOT) NULL
```

Da bi upit bio validan.

---

Skoro tačno — 9.5/10. Samo sintaksa mora imati naziv kolone:

```sql
WHERE deleted_at IS NULL
```

ili:

```sql
WHERE deleted_at IS NOT NULL
```

Ne:

```sql
WHERE IS NULL
```

Razlog je isti kao iz MySQL modula: NULL nije obična vrednost koju porediš sa =.

```text
deleted_at = NULL
→ UNKNOWN
```

```text
deleted_at IS NULL
→ TRUE/FALSE provera koju želimo
```

Placeholder tu nije problem. Problem je sam SQL operator. Ako upisujemo NULL, placeholder je sasvim dobar:

```php
$stmt->bindValue(':deleted_at', null, PDO::PARAM_NULL);
```

Ali ako pitamo da li je nešto NULL, koristimo IS NULL.
