Lekcija 18 — Dinamički IN (...) i zašto jedan placeholder nije cela lista

Ovo je vrlo praktična PDO zamka.

Recimo imamo:
$ids = [5, 8, 12];

i želimo:
SELECT *
FROM hotels
WHERE id IN (5, 8, 12);

Možda ti prvo padne na pamet:
$stmt = $pdo->prepare(
    'SELECT * FROM hotels WHERE id IN (:ids)'
);

$stmt->execute([
    'ids' => '5,8,12',
]);

Ali to nije isto što i:
IN (5, 8, 12)

Jer jedan placeholder predstavlja jednu vrednost.
Mentalno:
:ids
→ jedna vrednost

nije:
→ proizvoljan komad SQL sintakse
→ lista od N SQL parametara

Zato za tri vrednosti trebaju tri placeholder-a:
WHERE id IN (?, ?, ?)

U PHP-u ih možemo generisati:
$ids = [5, 8, 12];

$placeholders = implode(
    ',',
    array_fill(0, count($ids), '?')
);

Dobijamo:
?,?,?

pa:
$sql = "
    SELECT *
    FROM hotels
    WHERE id IN ($placeholders)
";

$stmt = $pdo->prepare($sql);
$stmt->execute($ids);

Ovde smo dinamički napravili samo SQL strukturu placeholder-a, 
dok same vrednosti i dalje idu odvojeno kroz execute().

Tok:
[5, 8, 12]
   ↓
broj elemenata = 3
   ↓
?,?,?
   ↓
prepare SQL
   ↓
execute([5, 8, 12])

Bitna bezbednosna razlika je:
implode(',', $ids)

direktno u SQL nije pristup koji želimo kada su vrednosti user-controlled.
Umesto toga pravimo samo:
?,?,?

na osnovu broja elemenata, a stvarni podaci i dalje prolaze kao parametri.
Edge case: prazna lista
Ako je:
$ids = [];

onda generisanje može dati:
WHERE id IN ()

što nije validan SQL.
Zato aplikacija treba unapred da odluči šta prazna lista znači.
Na primer:
if ($ids === []) {
    return [];
}

umesto da uopšte šalje query.
Mentalna mapa
placeholder
→ jedna SQL vrednost

3 vrednosti
→ 3 placeholder-a

IN (:ids)
→ nije automatska array ekspanzija u PDO-u

IN (?, ?, ?)
→ da

vrednosti
→ execute([...])

Mini interview pitanje 19
Zašto ovo nije ispravan način da prosledimo niz ID-jeva:
WHERE id IN (:ids)

sa:
$stmt->execute([
    'ids' => [5, 8, 12]
]);

i kako bi konceptualno napravio bezbedan PDO query za proizvoljan broj ID-jeva?

---

Primer je pogresan jer 1 placeholder je jedna vrednost.

Konceptualno bih:

Uzeo broj elemenata u nizu

Napravio toliko placeholdera, npr ?,?,?

Stavio to u prepare()

Poslao id-eve kroz execute()

---

Tačno — 10/10.
Upravo taj mentalni model:
1 placeholder
→ 1 vrednost

N vrednosti
→ N placeholder-a

Dakle:
$ids = [5, 8, 12];

$placeholders = implode(
    ', ',
    array_fill(0, count($ids), '?')
);

$stmt = $pdo->prepare(
    "SELECT * FROM hotels
     WHERE id IN ($placeholders)"
);

$stmt->execute($ids);

Ovde je bezbedno dinamičan samo broj ? znakova, 
dok stvarni ID-jevi i dalje prolaze kao parametri.
