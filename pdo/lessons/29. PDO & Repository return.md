# 29. PDO & Repository return

## Lekcija 29 — PDO i repository return values

Sad dolazimo do jedne praktične arhitektonske teme: šta repository treba da vraća.

Recimo:

```php
class UserRepository
{
    public function find(int $id): array|false
    {
        $stmt = $this->pdo->prepare(
            'SELECT id, name, email
             FROM users
             WHERE id = :id'
        );

        $stmt->execute([
            'id' => $id,
        ]);

        return $stmt->fetch();
    }
}
```

Ovde repository direktno vraća:

```text
array
ili
false
```

To je najjednostavniji pristup.
Ali možemo imati i model/DTO pristup:

```php
public function find(int $id): ?User
```

pa:

```php
$row = $stmt->fetch();

if (!$row) {
    return null;
}

return new User(
    id: (int) $row['id'],
    name: $row['name'],
    email: $row['email'],
);
```

Mentalno:

```text
PDO
→ sirovi DB rezultat
```

```text
Repository
→ može da ga pretvori u oblik koji aplikacija koristi
```

To lepo odvaja:

DB representation

od:

application/domain representation

Na primer baza može vratiti:

```php
[
    'id' => '15',
    'is_active' => '1',
]
```

a repository može vratiti objekat:

```text
User {
    id: 15,
    isActive: true
}
```

Dakle repository nije samo mesto gde stoji SQL. Često je i granica između:

```text
DB sveta
i
application sveta
```

## Mini interview pitanje 30

Zašto može biti korisno da repository ne vraća direktno svaki put sirovi `PDO::FETCH_ASSOC` rezultat,
nego da ga mapira u User, Booking, DTO ili neki drugi application-level objekat?

---

Zato sto onda Repository moze da pretvori DB rezultat u oblik koji app koristi.

---

Tačno — 9.7/10.
Suština je upravo:

```text
PDO / DB
→ sirovi rezultat
```

```text
Repository
→ mapiranje
```

```text
Application
→ dobija oblik koji razume i koristi
```

Na primer baza može vratiti:

```php
[
    'id' => '15',
    'is_active' => '1',
]
```

a repository:

```php
return new User(
    id: (int) $row['id'],
    isActive: (bool) $row['is_active'],
);
```

Time ostatak aplikacije ne mora da zna detalje poput:

```text
kako PDO vraća podatke
kako se zovu DB kolone
da li je boolean stigao kao 0/1
koji fetch mode koristimo
```

To je dobra granica između persistence sloja i ostatka aplikacije.
