# 38. Dynamic filters with PDO

## Lekcija 38 — Dinamički filteri sa PDO

Ovo je veoma praktično za stvari koje si već radio u BookYourHotel-u i Automarket-u.

Recimo korisnik može opciono poslati:

```text
city
min_price
max_price
status
```

Ne želimo da pravimo deset različitih SQL query-ja.
Krećemo od:

```php
$sql = 'SELECT * FROM hotels WHERE 1 = 1';

$params = [];
```

Pa dodajemo samo filtere koji postoje:

```php
if ($city !== null) {
    $sql .= ' AND city = :city';
    $params['city'] = $city;
}

if ($minPrice !== null) {
    $sql .= ' AND base_price >= :min_price';
    $params['min_price'] = $minPrice;
}

if ($maxPrice !== null) {
    $sql .= ' AND base_price <= :max_price';
    $params['max_price'] = $maxPrice;
}
```

Na kraju:

```php
$stmt = $pdo->prepare($sql);
$stmt->execute($params);
```

Ako korisnik pošalje samo:

```text
city = Novi Sad
min_price = 50
```

finalni SQL template praktično bude:

```sql
SELECT *
FROM hotels
WHERE 1 = 1
  AND city = :city
  AND base_price >= :min_price
```

a parametri:

```php
[
    'city' => 'Novi Sad',
    'min_price' => 50,
]
```

---

## Zašto je ovo bezbedno?

Dinamički menjamo samo SQL strukturu koju određuje naš PHP kod:

```php
$sql .= ' AND city = :city';
```

Korisnička vrednost i dalje ne ulazi direktno u SQL:

```text
Novi Sad
→ execute parameter
```

Dakle opet ista podela:

```text
kontrolisana SQL struktura
→ PHP gradi query
```

```text
user-controlled values
→ placeholders
```

---

## Ovo je zapravo low-level verzija onoga što

Laravel Query Builder radi kada napišeš nešto poput:

```php
Hotel::query()
    ->when($city, fn ($q) =>
        $q->where('city', $city)
    )
    ->when($minPrice, fn ($q) =>
        $q->where('base_price', '>=', $minPrice)
    );
```

Ispod toga opet mora da nastane SQL + bindings.

---

## Jedna zamka

Ne radimo:

```php
$sql .= " AND city = '$city'";
```

samo zato što SQL već dinamički gradimo.
Dinamički query je sasvim normalan; bitno je šta je dinamičko:

```text
AND city = :city       ✅
AND base_price >= :min ✅
```

AND city = '`$city`'     ❌

## Mini interview pitanje 39

Zašto je bezbedno da PHP uslovno doda:

```php
$sql .= ' AND city = :city';
```

a nije bezbedno da uradi:

```php
$sql .= " AND city = '$city'";
```

iako su oba primera „dinamičko građenje SQL-a“?

---

Ovo drugo nije bezbedno jer korisnicki unos direktno lepimo u upit. Treba slati kroz parametre

---

Tačno — 10/10.
Ključna razlika je:

```text
dinamički SQL fragment koji kontroliše aplikacija
→ bezbedno
```

```text
user-controlled vrednost direktno ulepljena u SQL
→ nije bezbedno
```

Dakle ovo je okej:

```php
$sql .= ' AND city = :city';
$params['city'] = $city;
```

jer aplikacija bira SQL strukturu, a korisnički podatak ide odvojeno kroz parameter binding.
Dok je ovo problem:

```php
$sql .= " AND city = '$city'";
```

jer user input postaje deo SQL stringa.
