# 41. PDO & reusable repo

## Lekcija 41 — PDO i reusable repository metode unutar transakcije

Važna posledica prethodne lekcije je da repository metoda ne treba da pretpostavlja:

„Ja uvek sam upravljam transakcijom.“

Na primer:

```php
class InventoryRepository
{
    public function decrease(int $roomId): void
    {
        $stmt = $this->pdo->prepare(
            'UPDATE room_inventory
             SET available = available - 1
             WHERE room_id = :room_id
               AND available > 0'
        );

        $stmt->execute([
            'room_id' => $roomId,
        ]);

        if ($stmt->rowCount() !== 1) {
            throw new RuntimeException('No availability');
        }
    }
}
```

Ova metoda ne zna da li je pozvana:

van transakcije

ili:

unutar transakcije koju je otvorio Service

I to je dobro.
Ako Service uradi:

```php
$this->pdo->beginTransaction();

try {
    $this->inventoryRepository->decrease($roomId);
    $bookingId = $this->bookingRepository->create(...);

    $this->pdo->commit();
} catch (Throwable $e) {
    if ($this->pdo->inTransaction()) {
        $this->pdo->rollBack();
    }

    throw $e;
}
```

obe repository metode automatski učestvuju u istoj transakciji zato što koriste isti PDO objekat.
Mentalno:

```text
Service
→ određuje atomic granicu
```

```text
Repository
→ samo izvršava SQL preko postojeće konekcije
```

To repository čini mnogo reusable.
