# 8. AuthService and AuthClass

## Module 10 — Authentication bez frameworka

### Lekcija 8/15 — Kako organizovati authentication logiku bez pravljenja “God Object” klase

Do sada smo napravili mentalne delove authentication sistema:

```text
User
UserRepository
password hashing
login flow
Session
session security
```

Sada ih treba povezati u jedan čist API koji ostatak aplikacije može da koristi.

Najvažniji mentalni model:

```text
AuthService
→ orkestrira authentication

UserRepository
→ zna kako da pronađe User-a

Session
→ zna kako da čuva auth state
```

`AuthService` ne treba da radi sve u aplikaciji.

Njegov posao je:

> Upravljanje authentication lifecycle-om korisnika.

---

## 1. Zašto uopšte pravimo Auth klasu?

Bez centralnog auth sloja lako završimo sa ovakvim kodom po controller-ima:

```php
$user = $users->findByEmail($email);

if ($user === null) {
    // ...
}

if (!password_verify($password, $user->passwordHash())) {
    // ...
}

session_regenerate_id(true);

$_SESSION['user_id'] = $user->id();
```

A onda drugi controller radi:

```php
if (!isset($_SESSION['user_id'])) {
    header('Location: /login');
    exit;
}
```

Treći:

```php
$user = $users->findById(
    $_SESSION['user_id']
);
```

Četvrti:

```php
unset($_SESSION['user_id']);
```

Authentication logika je sada razbacana kroz celu aplikaciju.

Bolje:

```php
$auth->attempt(...);
$auth->check();
$auth->user();
$auth->id();
$auth->logout();
```

Dakle:

```text
Controller
↓
AuthService
↓
Session + UserRepository
```

# 4. `attempt()`

`attempt()` dobija credentials:

```php
public function attempt(
    string $email,
    string $password
): bool
```

Njegov posao je:

```text
normalize email
↓
find user
↓
verify password
↓
proveri da li account sme da se loginuje
↓
login(user)
↓
true
```

Ako bilo šta ne uspe:

```text
false
```

Primer:

```php
public function attempt(
    string $email,
    string $password
): bool {
    $email = mb_strtolower(trim($email));

    $user = $this->users->findByEmail($email);

    if ($user === null) {
        return false;
    }

    if (!password_verify(
        $password,
        $user->passwordHash()
    )) {
        return false;
    }

    if (!$user->isActive()) {
        return false;
    }

    $this->login($user);

    return true;
}
```

Ovde je vrlo lepo razdvojeno:

```text
attempt()
→ credentials

login()
→ session state
```

# 7. Zašto odvajamo `login()` od `attempt()`?

Zato što korisnik ne mora uvek postati authenticated preko password forme.

Možemo imati:

```text

↓

↓

```

Ali možemo imati i:

```text

↓

↓

```

Ili kasnije:

```text

↓

↓

```

Dakle:

```text

→ jedan način potvrde identiteta

login()
→ generičko uspostavljanje auth state-a
```

To je dobar SRP.

# 8. `id()`

Minimalna implementacija:

```php
public function id(): ?int
{
    $id = $this->session->get('user_id');

    return is_int($id)
        ? $id
        : null;
}
```

Ili, ako session storage može vratiti numeric string:

```php
public function id(): ?int
{
    $id = $this->session->get('user_id');

    if ($id === null) {
        return null;
    }

    return (int) $id;
}
```

Mentalno:

```text
authenticated
→ int user ID

guest
→ null
```

Dakle:

```php
$auth->id();
```

može vratiti:

```text
17
```

ili:

```text
null
```

# 9. `check()`

Najjednostavnije:

```php
public function check(): bool
{
    return $this->id() !== null;
}
```

Dakle:

```text
user_id postoji
→ true

user_id ne postoji
→ false
```

Na primer:

```php
if ($auth->check()) {
    // authenticated
}
```

Ali ovde postoji važna nijansa.

Session može imati:

```text
user_id = 17
```

a user #17 možda više ne postoji.

Zato je ovo samo najjednostavnija implementacija.

Robusniji auth sistem može proveravati i da li `user()` zaista može biti resolved.

To ćemo detaljno rešiti u sledećoj lekciji.

# 10. `guest()`

Vrlo jednostavno:

```php
public function guest(): bool
{
    return !$this->check();
}
```

Dakle:

```text
check() = true
→ guest() = false

check() = false
→ guest() = true
```

Ovo:

```php
if ($auth->guest()) {
    // redirect to login
}
```

je često čitljivije od:

```php
if (!$auth->check()) {
```

Oba su validna.

# 11. `user()`

Ovo je jedna od najvažnijih metoda.

Minimalni flow:

```text

↓
UserRepository::findById()
↓
User | null
```

Na primer:

```php
public function user(): ?User
{
    $id = $this->id();

    if ($id === null) {
        return null;
    }

    return $this->users->findById($id);
}
```

Sada:

```php
$currentUser = $auth->user();
```

može dati:

```text
User
```

ili:

```text
null
```

# 12. `id()` i `user()` nisu ista stvar

`id()`:

```text
čita identity reference iz session-a
```

`user()`:

```text
učitava stvarnog User-a iz persistence sloja
```

Dakle:

```php
$auth->id();
```

je jeftinije:

```text
session lookup
```

dok:

```php
$auth->user();
```

može zahtevati:

```text
database query
```

To je važna razlika.

# 13. Šta ako User više ne postoji?

Recimo session kaže:

```text
user_id = 17
```

ali:

```php
$this->users->findById(17);
```

vrati:

```text
null
```

To znači da je auth state stale.

Robusniji AuthService treba da uradi nešto poput:

```text
user više ne postoji
↓
ukloni user_id iz session-a
↓
tretiraj kao guest
```

Na primer:

```php
public function user(): ?User
{
    $id = $this->id();

    if ($id === null) {
        return null;
    }

    $user = $this->users->findById($id);

    if ($user === null) {
        $this->session->forget('user_id');

        return null;
    }

    return $user;
}
```

Detaljno current-user resolution radimo u Lekciji 9.

# 14. Da li `check()` treba da koristi `id()` ili `user()`?

Imamo dve moguće strategije.

### Jednostavna

```php
public function check(): bool
{
    return $this->id() !== null;
}
```

Prednost:

```text
nema DB query-ja
```

Mana:

```text
stale user_id može dati true
```

### Stroža

```php
public function check(): bool
{
    return $this->user() !== null;
}
```

Prednost:

```text
proverava realnog current user-a
```

Mana:

```text
može napraviti DB query
```

Nema univerzalnog odgovora.

Za naš sistem ćemo u sledećoj lekciji napraviti dovoljno robustan model bez nepotrebnog query-ja na svakom pozivu.

Zamisli da tokom jednog request-a pozoveš:

Ne želiš nužno četiri ista SQL query-ja.

# 26. Kompletan minimalistički AuthService
```php
final class AuthService
{
    public function __construct(
        private UserRepository $users,
        private Session $session
    ) {}

    public function attempt(
        string $email,
        string $password
    ): bool {
        $email = mb_strtolower(
            trim($email)
        );

        $user = $this->users->findByEmail(
            $email
        );

        if ($user === null) {
            return false;
        }

        if (!password_verify(
            $password,
            $user->passwordHash()
        )) {
            return false;
        }

        if (!$user->isActive()) {
            return false;
        }

        if (password_needs_rehash(
            $user->passwordHash(),
            PASSWORD_DEFAULT
        )) {
            $newHash = password_hash(
                $password,
                PASSWORD_DEFAULT
            );

            $this->users->updatePasswordHash(
                $user->id(),
                $newHash
            );
        }

        $this->login($user);

        return true;
    }

    public function login(User $user): void
    {
        $this->session->regenerate();

        $this->session->put(
            'user_id',
            $user->id()
        );
    }

    public function id(): ?int
    {
        $id = $this->session->get(
            'user_id'
        );

        if ($id === null) {
            return null;
        }

        return (int) $id;
    }

    public function user(): ?User
    {
        $id = $this->id();

        if ($id === null) {
            return null;
        }

        return $this->users->findById($id);
    }

    public function check(): bool
    {
        return $this->user() !== null;
    }

    public function guest(): bool
    {
        return !$this->check();
    }

    public function logout(): void
    {
        $this->session->forget(
            'user_id'
        );
    }
}
```

Ovo je već sasvim pristojan Vanilla PHP authentication service.

Kasnije ćemo još poboljšati:

current user resolution
logout lifecycle
remember me

ali skeleton je vrlo zdrav.

