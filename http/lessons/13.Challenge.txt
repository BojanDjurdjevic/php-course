Coding challenge 1 — JSON API endpoint
Krećemo sada coding zadatke, opet jedan po jedan.
Frontend šalje:
POST /users.php
Content-Type: application/json
Accept: application/json

body:
{
    "name": "  Bojan  ",
    "email": "bojan@example.com",
    "age": 40
}

Napiši users.php koji treba da:
1. prihvati samo POST; za drugo vrati 405 i Allow: POST,
2. zahteva application/json; inače 415,
3. pročita raw body preko php://input,
4. koristi JSON_THROW_ON_ERROR; malformed JSON → 400,
5. proveri da je root decoded vrednost array,
6. name mora biti neprazan string nakon trim(),
7. email mora biti validan email,
8. age mora biti pravi PHP int i između 18 i 100,
9. validation failure → 422,
10. ako je sve dobro, vrati 201 Created i JSON:
{
    "data": {
        "name": "Bojan",
        "email": "bojan@example.com",
        "age": 40
    }
}

Ne mora baza. Samo HTTP + JSON + validation pipeline.

---

<?php 

header('Content-Type: application/json; charset=UTF-8');

$method = $_SERVER['REQUEST_METHOD'];

if($method !== 'POST') {
    header('Allow: POST');

    http_response_code(405);

    echo json_encode([
        'error' => 'Method not allowed!'
    ], JSON_UNESCAPED_UNICODE);

    exit;
}

$content = $_SERVER['CONTENT_TYPE'] ?? '';

$contentType = strtolower(
    trim(explode(';', $content)[0])
);

if($contentType !== 'application/json') {
    http_response_code(415);

    echo json_encode([
        'error' => 'Invalid content, expected JSON.'
    ], JSON_UNESCAPED_UNICODE);

    exit;
}

$raw = file_get_contents('php://input');

try {
    $data = json_decode($raw, true, 512, JSON_THROW_ON_ERROR);
} catch (JsonException $e) {
    http_response_code(400);

    // opciono: logovati $e->message() 

    echo json_encode([
        'error' => 'Invalid JSON sent.'
    ], JSON_UNESCAPED_UNICODE);

    exit;
}

if(!is_array($data)) {
    http_response_code(422);

    echo json_encode([
        'error' => 'JSON object expected!'
    ], JSON_UNESCAPED_UNICODE);

    exit;
}

$name = $data['name'] ?? null;
$email = $data['email'] ?? null;

if(!is_string($name) || trim($name) === '') {
    http_response_code(422);

    echo json_encode([
        'error' => 'Name is required and must be string.'
    ], JSON_UNESCAPED_UNICODE);

    exit;
}

$name = trim($name);

if(!is_string($email)) {
    http_response_code(422);

    echo json_encode([
        'error' => 'The email is required and must be valid email address!'
    ], JSON_UNESCAPED_UNICODE);

    exit;
}

$email = trim($email);

if(!filter_var($email, FILTER_VALIDATE_EMAIL)) {
    http_response_code(422);

    echo json_encode([
        'error' => 'The email is required and must be valid email address!'
    ], JSON_UNESCAPED_UNICODE);

    exit;
}

if(!isset($data['age']) || !is_int($data['age']) || $data['age'] < 18 || $data['age'] > 100) 
{
    http_response_code(422);

    echo json_encode([
        'error' => 'Age must be valid number with range from 18 to 100.'
    ], JSON_UNESCAPED_UNICODE);

    exit;
}

http_response_code(201);

echo json_encode([
    'data' => [
        'name' => $name,
        'email' => $email,
        'age' => $data['age']
    ]
], JSON_UNESCAPED_UNICODE);

exit;

Coding challenge 2 — File upload endpoint

Napravi upload.php koji:

<form method="POST" enctype="multipart/form-data">
    <input type="file" name="photo">
</form>

treba da obradi ovako:

1. prihvata samo POST, inače 405 + Allow: POST,
2. očekuje $_FILES['photo'],
3. proverava upload error,
4. maksimalna veličina je 3 MB,
5. dozvoljeni MIME tipovi su samo:
   - image/jpeg
   - image/png
   - image/webp
6. MIME proveri preko finfo, ne preko $file['type'],
7. generiše random filename preko random_bytes(),
8. čuva u:uploads/15/
   
   gde za sada možemo hardkodovati:$userId = 15;
9. kreira direktorijum ako ne postoji,
10. koristi move_uploaded_file(),
11. ako upload uspe, vrati 201 i JSON tipa:
{
    "data": {
        "path": "uploads/15/a1b2c3d4.webp"
    }
}

12. ako MIME nije dozvoljen → 415,
13. ako je fajl prevelik → 413,
14. ostale validation/upload greške možeš vratiti kao 422.

---

<?php

header('Content-Type: application/json; charset=UTF-8');

$method = $_SERVER['REQUEST_METHOD'];

if($method !== 'POST') {
    header('Allow: POST');

    http_response_code(405);

    exit('Error: Unsupported method!');
}

$file = $_FILES['photo'] ?? null;

$maxSize = 3 * 1024 * 1024;

$allowedTypes = [
    'image/jpeg' => 'jpeg',
    'image/png' => 'png',
    'image/webp' => 'webp'
];

if($file === null) {
    http_response_code(422);

    exit('Error: The photo is required!');
}

if($file['error'] !== UPLOAD_ERR_OK) {
    http_response_code(422);

    exit('Error: Upload failed!');
}

if($file['size'] > $maxSize) {
    http_response_code(413);

    exit('Error: The file is too large!');
}

$finfo = new finfo(FILEINFO_MIME_TYPE);

$mime = $finfo->file($file['tmp_name']);

if(!isset($allowedTypes[$mime])) {
    http_response_code(415);

    exit('Error: Unsupported mime type!');
}

$extension = $allowedTypes[$mime];

$fileName = bin2hex(random_bytes(16)) . '.' . $extension;

$user_id = 15;

$uploadDir = __DIR__ . "/uploads/$user_id";

if(!is_dir($uploadDir) && !mkdir($uploadDir, 0755, true) && !is_dir($uploadDir)) {
    http_response_code(500);

    exit('Error: COuld not create file directory');
}

$relativePath = "uploads/$user_id/$fileName";

$destination = __DIR__ . DIRECTORY_SEPARATOR . 'uploads' . DIRECTORY_SEPARATOR . $user_id . DIRECTORY_SEPARATOR . $fileName;

if(!move_uploaded_file($file['tmp_name'], $destination)) {
    http_response_code(500);

    exit('Error: Could not upload the file!');
}

http_response_code(201);

echo json_encode([
    'data' => [
        'path' => $relativePath
    ]
], JSON_UNESCAPED_UNICODE);

Coding challenge 3 — POST → Redirect → GET + session flash

Napravi dva fajla:
create.php
store.php

create.php prikazuje formu:

<form method="POST" action="store.php">
    <input type="text" name="name">
    <input type="email" name="email">
    <button type="submit">Save</button>
</form>

store.php treba da:

1. prima samo POST,
2. validira da name nije prazan,
3. validira email,
4. nema baze — samo simuliramo uspešan save,
5. ako validacija padne, sačuva error poruke i stari input u $_SESSION,
6. uradi redirect nazad na create.php,
7. ako je uspešno, sačuva flash poruku:User created successfully!
8. uradi 303 redirect na create.php,
9. create.php treba da prikaže flash/errors/old input,
10. nakon prikaza ih ukloni iz session-a da se ne pojavljuju ponovo na sledećem refresh-u.

Mentalni model:

POST
→ session
→ redirect
→ GET
→ read flash
→ remove flash

---

Coding challenge 4 — Request inspector

Napravi jedan request.php koji vraća JSON sa informacijama o trenutnom requestu.

Treba da vrati nešto ovakvo:
{
    "method": "GET",
    "uri": "/request.php?page=2",
    "query_string": "page=2",
    "query": {
        "page": "2"
    },
    "content_type": null,
    "user_agent": "...",
    "ip": "127.0.0.1"
}

Zahtevi:
- response mora biti application/json,
- koristi odgovarajuće vrednosti iz $_SERVER,
- query uzmi iz $_GET,
- ako header/vrednost ne postoji, vrati null,
- nemoj izmišljati IP iz X-Forwarded-For; koristi REMOTE_ADDR,
- json_encode() sa JSON_UNESCAPED_UNICODE | JSON_PRETTY_PRINT,
- endpoint neka radi za bilo koju HTTP metodu.


---

<?php

header('Content-Type: application/json; charset=UTF-8');

echo json_encode([
    'method' => $_SERVER['REQUEST_METHOD'] ?? null,
    'uri' => $_SERVER['REQUEST_URI'] ?? null,
    'query_string' => $_SERVER['QUERY_STRING'] ?? null,
    'query' => $_GET,
    'content_type' => $_SERVER['CONTENT_TYPE'] ?? null,
    'user_agent' => $_SERVER['HTTP_USER_AGENT'] ?? null,
    'ip' => $_SERVER['REMOTE_ADDR'] ?? null,
], JSON_UNESCAPED_UNICODE | JSON_PRETTY_PRINT);
