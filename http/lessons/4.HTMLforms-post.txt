U process.php možemo:
<?php

Dobijaš:
Array
(
    [name] => Bojan
    [email] => bojan@example.com
)

Konceptualno:
$_POST = [
    'name' => 'Bojan',
    'email' => 'bojan@example.com',
];

Dakle potpuno ista ideja koju smo videli sa $_GET.
QUERY STRING
?page=2&sort=price

        ↓ PHP

$_GET = [
    'page' => '2',
    'sort' => 'price',
];

Nasuprot tome:
POST BODY
name=Bojan&email=bojan...

        ↓ PHP

$_POST = [
    'name' => 'Bojan',
    'email' => 'bojan@example.com',
];

PHP definiše $_POST kao superglobalni asocijativni niz podataka iz POST zahteva kada je body kodiran kao application/x-www-form-urlencoded ili multipart/form-data.

---------------------------------------------

application/x-www-form-urlencoded
Ovo je default za običnu HTML POST formu:
<form method="POST">

Browser šalje nešto nalik:
name=Bojan&city=Novi+Sad&age=40

Izgleda skoro kao query string.
I jeste vrlo sličan encoding:
key=value&key=value

Razlika je gde se nalazi.
GET:
URL

?name=Bojan&city=Novi+Sad

POST:
BODY

name=Bojan&city=Novi+Sad

MDN opisuje application/x-www-form-urlencoded upravo kao key/value parove razdvojene sa &, uz URL/percent encoding specijalnih karaktera.

Checkbox ima jednu čuvenu zamku

    'newsletter' => '0',

$newsletter = ($_POST['newsletter'] ?? '0') === '1';

$newsletter = $request->boolean('newsletter');

----------------------------------------------------

Content-Type


Ovo je jako bitno!!!

PHP ne kaže samo:
„Aha, POST je — napuniću $_POST.“

Nije tako jednostavno.
Bitno je u kom formatu je request body poslat.
Klasična forma:
Content-Type: application/x-www-form-urlencoded

→ PHP popunjava:
$_POST

Forma sa file uploadom:
Content-Type: multipart/form-data

→ PHP popunjava:
$_POST
$_FILES

Ali ako JavaScript pošalje:
Content-Type: application/json

sa:
{
    "name": "Bojan",
    "email": "bojan@example.com"
}

onda:
$_POST

neće automatski sadržati taj JSON.
PHP dokumentacija eksplicitno navodi da $_POST automatski radi 
za application/x-www-form-urlencoded i multipart/form-data; 
za druge content type-ove poput application/json koristi se raw body preko php://input.

----------------------------------------------------------

multipart/form-data

Ako imaš:
<form
    method="POST"
    enctype="multipart/form-data"
>

browser šalje body u delovima.
Recimo:
text field
file
text field
file

svaki postaje poseban part, odvojen tzv. boundary vrednošću. multipart/form-data je encoding koji se koristi kada forma šalje fajlove. MDN Web Docs
PHP tada tekstualne vrednosti stavlja u:
$_POST

a uploadovane fajlove u:
$_FILES
