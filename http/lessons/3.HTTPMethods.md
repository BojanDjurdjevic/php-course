# 3.HTTPMethods

| Method | Tipična namena | Safe? | Idempotent? |
| --- | --- | --- | --- |
| `GET` | čitanje resursa | ✅ | ✅ |
| `POST` | kreiranje / akcija | ❌ | ❌ |
| `PUT` | kompletna zamena resursa | ❌ | ✅ |
| `PATCH` | parcijalna izmena | ❌ | nije garantovano |
| `DELETE` | brisanje resursa | ❌ | ✅ |
| `HEAD` | kao GET, bez body-ja | ✅ | ✅ |
| `OPTIONS` | koje su mogućnosti endpointa | ✅ | ✅ |

Safe ≠ idempotent

Safe
Safe znači:

Klijent ne zahteva promenu server state-a.

```text
GET
HEAD
OPTIONS
```

### Idempotent

Idempotent znači:

> Više identičnih requestova ima isti intended effect kao jedan.

Zato:

GET -> safe + idempotent

ALI

DELETE -> NOT safe - BUT idempotent

---

```php
$method = $_SERVER['REQUEST_METHOD'];

switch ($method) {
    case 'GET':
        echo 'Read resource';
        break;

    case 'POST':
        echo 'Create resource';
        break;

    case 'PUT':
        echo 'Replace resource';
        break;

    case 'PATCH':
        echo 'Update resource';
        break;

    case 'DELETE':
        echo 'Delete resource';
        break;

    default:
        http_response_code(405);
        echo 'Method Not Allowed';
}
```

MODERNIJE:

```php
$method = $_SERVER['REQUEST_METHOD'];

$message = match ($method) {
    'GET' => 'Read resource',
    'POST' => 'Create resource',
    'PUT' => 'Replace resource',
    'PATCH' => 'Update resource',
    'DELETE' => 'Delete resource',
    default => null,
};

if ($message === null) {
    http_response_code(405);
    exit('Method Not Allowed');
}

echo $message;
```

---

REZIME:

```text
GET
"daj mi podatke"
safe + idempotent
```

```text
POST
"obradi ovo / napravi nešto"
unsafe + non-idempotent
```

```text
PUT
"zameni ovaj resurs"
unsafe + idempotent
```

```text
PATCH
"izmeni ovaj deo"
unsafe + not guaranteed idempotent
```

```text
DELETE
"ukloni resurs"
unsafe + idempotent
```

```text
HEAD
"GET, ali bez body-ja"
```

```text
OPTIONS
"koje mogućnosti podržavaš?"
```

---

SAFE = da li request traži promenu state-a?

IDEMPOTENT = da li 1 i N identičnih requestova imaju isti intended effect?
