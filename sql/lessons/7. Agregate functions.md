# 7. Agregate functions

## Lekcija 7 — Aggregate funkcije: COUNT, SUM, AVG, MIN, MAX

Sad prelazimo na query-je koji ne vraćaju samo pojedinačne redove, nego računaju nešto nad skupom redova.
Najvažnije aggregate funkcije su:

```text
COUNT → koliko
SUM   → zbir
AVG   → prosek
MIN   → najmanja vrednost
MAX   → najveća vrednost
```

Recimo:

```sql
SELECT COUNT(*)
FROM hotels;
```

vraća broj hotela.

```sql
SELECT AVG(base_price)
FROM hotels;
```

vraća prosečnu cenu.

```sql
SELECT MIN(base_price), MAX(base_price)
FROM hotels;
```

vraća najnižu i najvišu cenu.

```sql
SELECT SUM(base_price)
FROM hotels;
```

sabira sve vrednosti base_price.
Možemo i filtrirati pre agregacije:

```sql
SELECT AVG(base_price)
FROM hotels
WHERE is_active = TRUE;
```

Znači:

```text
prvo WHERE odabere redove
onda AVG računa prosek nad tim redovima
```

To je važan mentalni model.
Još jedna nijansa:

```php
COUNT(*)
```

broji redove.
Dok:

```php
COUNT(phone)
```

broji samo redove gde phone nije NULL.
Dakle:

```text
COUNT(*)      → svi redovi
COUNT(column) → samo non-NULL vrednosti te kolone
```

Možeš i dati alias:

```sql
SELECT COUNT(*) AS total_hotels
FROM hotels;
```

pa rezultat bude čitljiviji:

```text
total_hotels
------------
47
```

```text

```

```text

```

---

Tačno — 10/10. Query je čist i potpuno ispravan:

```sql
SELECT
    COUNT(*) AS total_hotels,
    AVG(base_price) AS average_price,
    MIN(base_price) AS min_price,
    MAX(base_price) AS max_price
FROM hotels
WHERE is_active = TRUE;
```

Posebno je važno što WHERE ide pre agregacije u logičkom smislu:

prvo ograničimo skup na aktivne hotele, pa onda nad tim skupom računamo COUNT, AVG, MIN i MAX.
