# 3. Visibility - public - protected - private

## Lekcija 3 — Visibility: public, protected, private

Sada dolazimo do jedne od najvažnijih OOP ideja: enkapsulacije.

Ako imamo:

```php
class User
{
    public string $email;
}
```

onda bilo ko spolja može:

```php
$user->email = 'bilo-sta';
```

To znači da objekat nema kontrolu nad sopstvenim stanjem.
Sa visibility modifier-ima određujemo ko sme da pristupi čemu.

```text
public
→ dostupno svuda
```

```text
protected
→ dostupno unutar klase i child klasa
```

```text
private
→ dostupno samo unutar same klase
```

Na primer:

```php
class User
{
    private string $email;

    public function __construct(string $email)
    {
        $this->email = $email;
    }

    public function email(): string
    {
        return $this->email;
    }
}
```

Spolja ne možeš:

```php
$user->email = 'test@test.com'; // greška
```

ali možeš:

```php
echo $user->email();
```

---

## Zašto je to dobro?

Jer klasa kontroliše kako se stanje čita i menja.
Na primer:

```php
class User
{
    private string $email;

    public function __construct(string $email)
    {
        $this->changeEmail($email);
    }

    public function changeEmail(string $email): void
    {
        if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
            throw new InvalidArgumentException('Invalid email.');
        }

        $this->email = $email;
    }

    public function email(): string
    {
        return $this->email;
    }
}
```

Sada ne može neko spolja tek tako da ubaci nevalidan email.
Mentalno:

```text
private property
→ objekat čuva svoje stanje
```

```text
public method
→ kontrolisana vrata za pristup/promenu
```

To je enkapsulacija.
protected ćemo detaljnije kad stignemo do inheritance-a, jer tada ima najviše smisla.

## Šta time dobijamo sa stanovišta kontrole nad stanjem objekta?

---

Tako mozemo kontrolisano da pristupamo podatku a da ne moze tek tako spolja da se menja

---

Tačno — 10/10.
To je srž enkapsulacije:

```text
public property
→ bilo ko spolja može direktno menjati stanje
```

```text
private property + public method
→ objekat sam kontroliše kako se stanje menja
```

Time možemo da uvedemo pravila:

```php
public function changeEmail(string $email): void
{
    if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
        throw new InvalidArgumentException('Invalid email');
    }

    $this->email = $email;
}
```

Dakle ne štitimo property samo “da ga sakrijemo”, nego zato da objekat može da garantuje svoje invariants.
