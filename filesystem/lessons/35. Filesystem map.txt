fopen()

| Mode          | Značenje |
|------------------------------------------------------------------------|
| `r`           | read; fajl mora postojati |
| `w`           | write; **truncate ako postoji**, create ako ne postoji |
| `a`           | append; piše na kraj, create ako ne postoji |
| `x`           | create for writing; **fail ako već postoji** |
| `r+`          | read + write, bez truncate-a |
| `w+`          | read + write + truncate/create |
| `a+`          | read + append/create |
