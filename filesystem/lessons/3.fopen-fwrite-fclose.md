# 3.fopen-fwrite-fclose

## Lekcija 3 — `fopen()`, `fread()`, `fwrite()`, `fclose()`

`file_get_contents()` i `file_put_contents()` su odlični kada želiš da odjednom pročitaš ili upišeš sadržaj.

Ali PHP ima i niži nivo rada preko file handle-a.
Na primer:

```php
$handle = fopen($path, 'r');
```

`fopen()` otvara fajl i vraća resource/stream handle koji koristiš za dalje operacije.
Ako ne uspe:

false

pa:

```php
$handle = fopen($path, 'r');

if ($handle === false) {
    throw new RuntimeException('Could not open file.');
}
```

Onda možeš:

```php
$content = fread(
    $handle,
    filesize($path)
);
```

i na kraju:

```php
fclose($handle);
```

Mentalno:

```text
fopen
↓
dobiješ handle
↓
read/write
↓
fclose
```

---

## Modes su veoma važni

Na primer:

```php
fopen($path, 'r');
```

znači:

```text
read only
file mora postojati
```

```php
fopen($path, 'w');
```

znači:

```text
write
ako postoji → truncate na 0 bytes
ako ne postoji → napravi
```

Ovo je važna zamka: 'w' briše postojeći sadržaj čim otvoriš fajl.

```php
fopen($path, 'a');
```

znači:

```text
append
piši na kraj
napravi fajl ako ne postoji
```

```php
fopen($path, 'x');
```

je zanimljiv:

```text
create for writing
ali FAIL ako fajl već postoji
```

To može biti korisno kada ne želiš accidental overwrite.
Postoje i + varijante:

```text
r+ → read + write
w+ → read + write, truncate/create
a+ → read + append
```

Za sada mi je najvažnije da bez gledanja znaš:

```text
r → read
w → write + overwrite/truncate
a → append
x → create only if nonexistent
```

```php
fwrite()
```

Primer:

```php
$handle = fopen($path, 'a');

if ($handle === false) {
    throw new RuntimeException('Could not open file.');
}

$bytes = fwrite(
    $handle,
    "New log line\n"
);

if ($bytes === false) {
    fclose($handle);

    throw new RuntimeException('Could not write file.');
}

fclose($handle);
```

I `fwrite()` opet vraća:

```text
int broj upisanih bytes
ili false
```

## Kada koristiti shortcut funkcije, a kada handle?

Za običan mali config/text fajl:

```php
file_get_contents()
file_put_contents()
```

su često najčistije.
Za veliki fajl, streaming, parcijalno čitanje/pisanje, iterativnu obradu ili finiju kontrolu:

```php
fopen()
fread()
fgets()
fwrite()
fclose()
```

imaju više smisla.
Na primer ogroman log fajl ne želiš nužno ceo da ubaciš u RAM preko:

```php
file_get_contents($hugeFile);
```

nego možeš da ga čitaš liniju po liniju.

## Pitanje

Šta će se desiti ako imamo fajl:

notes.txt

Hello Bojan

i uradimo:

```php
$handle = fopen($path, 'w');

fwrite($handle, 'PHP');

fclose($handle);
```

A šta bi bilo drugačije da smo koristili:

```php
fopen($path, 'a');
```

Objasni razliku između w i a svojim rečima.

---

```text
w
→ write
→ create ako ne postoji
→ truncate ako postoji
```

```text
a
→ append
→ create ako ne postoji
→ ne briše postojeći sadržaj
```
